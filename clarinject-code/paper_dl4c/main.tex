\section*{Impact Statement}

This paper studies a security vulnerability in collaborative coding agents: the
possibility that adversarial content injected through the clarification-answer channel
can redirect agent behavior in harmful ways. The intended societal impact is
\emph{positive}---by surfacing and quantifying this vulnerability, we enable
practitioners to build safer agent systems.

All adversarial payloads used in our benchmark are synthetic and clearly labeled as
test cases. They are evaluated inside a sandboxed environment with no real network
access, and exfiltration targets use the reserved domain \texttt{example-sandbox.invalid}.
No real systems are targeted or harmed by this research.

We acknowledge a dual-use risk: detailed knowledge of injection patterns could be
misused. We mitigate this by (1) restricting our study to injection styles already
documented in the public adversarial-prompting literature, and (2) pairing each
attack analysis with a corresponding defense evaluation. We follow responsible
disclosure practices: if our benchmark reveals undocumented attack vectors, we will
coordinate with model providers before public release.
