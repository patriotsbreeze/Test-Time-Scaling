\section*{Impact Statement}

This paper studies a security vulnerability in collaborative coding agents: the
possibility that adversarial content injected through the clarification-answer channel
can redirect agent behavior in harmful ways. The intended societal impact is
\emph{positive}---by surfacing and quantifying this vulnerability, we enable
practitioners to build safer agent systems.

All adversarial payloads in our benchmark are synthetic and clearly labeled as
test cases, evaluated in a sandboxed environment with no real network access.
Exfiltration targets use the reserved domain \texttt{example-sandbox.invalid}.
No real systems are targeted or harmed.

We acknowledge a dual-use risk: knowledge of injection patterns could be misused.
We mitigate this by (1) restricting our study to injection styles already documented
in the public adversarial-prompting literature, and (2) pairing every attack analysis
with a corresponding defense evaluation. If our benchmark reveals undocumented attack
vectors, we will follow coordinated disclosure with model providers before public release.
